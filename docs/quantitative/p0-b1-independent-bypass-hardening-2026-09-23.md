## Purpose and Boundary

This is a **narrow hardening package**, deliberately separate from the paused P0-B1 integration and from the deferred P0-B1c exception-intelligence work. It closes six independently discovered bypasses in current `main` that allowed legacy fraud values to influence automated output, publication, or a tenantless read path. It does not rebase, modify, stage, or merge the paused P0-B1 integration worktree.

The package adopts the already owner-approved P0-B1 policy: a stored fraud score, risk level, indicator, threshold, heuristic, or legacy aggregate cannot supply automated fraud authority. It may remain retained raw evidence, but it cannot decide, rank, route, certify, learn from, or publish an automated fraud conclusion. Until a future owner-approved policy defines qualified evidence and authority, consumers must return the actionable manual-review hold.

> **Actionable P0-B1 hold:** Automated fraud scoring, risk classification, routing, certification, and publication are withheld because current evidence has no qualified governing authority. The hold identifies the missing claim-linked evidence, human-reviewed provenance, and qualified policy authority, and states the evidence and review action required to resolve it.

## Shared Contract

Two small shared modules make the hardening independently testable without importing the paused integration package.

| Module                                              | Responsibility                                                                                                                                                                      |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `server/evidence-governance/p0FraudDecisionHold.ts` | Owns the immutable baseline hold, copies nested values per response, and provides the required-evidence and resolver text.                                                          |
| `server/reporting/p0FraudPresentation.ts`           | Renders the HTML/plain-text abstention and recursively removes fraud-specific values from a presentation payload while preserving non-fraud evidence.                               |
| `client/src/components/ValidationGate.tsx`          | Strictly validates the P0-B1 hold at the active validation consumer before any legacy validation result is interpreted and supplies an actionable fallback for malformed sentinels. |

The presentation helper is intentionally separate from the collision-physics boundary. P0-A-2 remains responsible for physics eligibility and publication; P0-B1 remains responsible for fraud authority and fraud disclosure.

## Out of Scope and Sequencing

The package does **not** implement P0-B1c, redefine the nine owner-approved authority policies, alter physics evidence eligibility, or modify the paused P0-B1 integration worktree. It does not remove unrelated fraud analytics, portfolio reporting, snapshot, learning, or exception-intelligence consumers discovered in the combined inventory; those remain explicitly deferred for separately scoped follow-ups.

Once this hardening package is independently reviewed, validated, approved, and merged, the next authorized work is the previously approved P0-B1 integration plan. That integration must rebase onto this merge, preserve this package's hold contract and regressions, preserve P0-A-2 collision-physics invariants, and remove the `fraudScoreAdjusted` fallback before its own combined validation.
