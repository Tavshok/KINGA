# KINGA Architecture Decision Records

**Author:** Tavonga Shoko, Lead Engineer

This directory contains the Architecture Decision Records (ADRs) for the KINGA AutoVerify AI platform. Each ADR documents a significant architectural decision, its context, the decision made, and the consequences.

ADRs are immutable once accepted. If a decision is reversed, a new ADR is created that supersedes the original.
